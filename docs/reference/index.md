# API reference

Information-oriented, exhaustive descriptions. Reach for these when you know what
you want and need the exact shape.

- [The `seiva` CLI](cli.md) — every command and flag
- [Settings and environment](settings.md) — every configuration variable
- [The contract descriptor](contract-descriptor.md) — `Facade`, `FacadeDescriptor`,

- [The crates](crates/index.md) — what each `seiva-*` / `delonix-seiva` crate owns

The full type-level API is generated by `cargo doc --workspace --no-deps` (every
public item is documented; rustdoc is the source of truth for signatures).
