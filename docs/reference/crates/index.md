- `seiva-openapi` — the OpenAPI generator
- `seiva-identity`, `seiva-auth`, `seiva-config`, `seiva-cqrs`, `seiva-messaging`, `seiva-webhooks`, `seiva-grpc`, `seiva-server`, `seiva-testing`, `seiva-cli`
- Full API docs are generated by `cargo doc`
