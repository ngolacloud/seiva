# Glossary

**Facade** — a module's versioned public contract: a trait annotated with
`#[seiva::facade]`. The single source of truth from which the transports, the
OpenAPI document and the permission checks are derived.

**FacadeDescriptor** — the machine-readable form of a facade (name, version,
methods, each method's `requires` permission and signature), generated by the macro
and read by the generators. See [the contract descriptor](reference/contract-descriptor.md).

**Controller** — the transport adapter, annotated `#[seiva::controller]`, that turns
a facade impl into an axum router (`<trait>_router`).

**Module** — a unit of the application, made of five layer crates (facade, domain,
application, infrastructure, interface). It owns its data and exposes one contract.

**Layer / the dependency rule** — the fixed direction of dependencies between the
five crates, enforced by the compiler. See [Architecture](architecture.md).

**Port** — a trait-only boundary (in `seiva-ports`: `UnitOfWork`, `EventPublisher`,
`Clock`, `IdGenerator`, plus a module's repository trait) that the application layer
codes against, so it is testable with no server or database.

**DORM** — the Delonix ORM, Seiva's default data layer, an **independent product**
wired in through the optional `dorm` feature. The framework core never depends on it.

**DTO** — a data transfer object: the explicit wire type (never a domain entity),
deriving `serde`, `Validate` and `WireSchema`.

**`Valid<T>`** — the extractor that deserialises and validates a request body,
producing an RFC 9457 `422` on failure.

**WireSchema** — the trait (and `#[derive(WireSchema)]`) by which a DTO contributes
its real JSON Schema to the OpenAPI document, with no reflection. See
[ADR 0007](adr/0007-wire-schema-contract-fidelity.md).

**Principal** — a verified caller identity (subject, tenant, permissions), produced
by an `Authenticator` from a bearer token. See [Authentication](topics/authentication.md).

**Authenticator** — the deny-by-default trait that turns a bearer into a `Principal`
(`TokenAuthenticator` for dev, `JwtAuthenticator` for OIDC/JWT).

**`Scoped<T>`** — the fail-closed wrapper that makes object-level authorization a
compile-time concern (BOLA prevention). See [Authorization](topics/authorization.md).

**`permission_guard` / `#[requires("…")]`** — function-level authorization: the
permission a caller must hold for a route, read from the descriptor.

**`router_with_modules`** — the application builder that merges module routers
**before** applying the framework layers, so authn/security/rate-limit apply to
module routes. See [the transport layer](topics/transport/index.md).

**Composition root** — `apps/<name>-api`: where concrete adapters are chosen and the
modules are assembled into a service. Holds no business logic.

**Fitness function** — a test that guards an architectural invariant and fails the
build if it is broken (run with `seiva lint`).

**ADR** — an Architecture Decision Record. See [the ADR index](internals/adrs.md).
